### 🛡️ [MedSafe-R — Medical Device Reliability & Patient Safety Intelligence](https://github.com/VictoriaE-ai/MedSafe-R)

**Status: Exploratory analysis and internal baseline evaluation completed; further development ongoing**

A clinical-engineering portfolio prototype investigating equipment maintenance history, downtime, simulated safety events and prioritisation of devices for engineering review.

- Reproducible Python analysis using corrected **synthetic** medical-device records.
- Overdue preventive maintenance, failure/downtime and departmental reliability analysis.
- Internal comparisons of logistic regression, random forest and an engineering-priority heuristic.
- Published chart report, offline HTML analysis and documented methods.

**[📁 Explore analysis, charts and reports](https://github.com/VictoriaE-ai/MedSafe-R)**

**Stack:** Python · pandas · NumPy · scikit-learn · Matplotlib · Excel

*Power BI updates, model explanations and external validation are not yet complete. This project does not claim validated clinical performance.*

### 🤖 [VHA-AIRAF — AI Readiness Assessment Framework](https://github.com/VictoriaE-ai/VHA-AIRAF)

**Status: Development prototype with a hosted demonstration**

An evidence-informed framework exploring how adult social care organisations in England might assess organisational readiness for a **specific proposed AI use case**.

- **30 assessment questions** across **10 readiness pillars**.
- **Four critical gates** covering data fitness, governance, information protection and safety/oversight.
- Python scoring calculator, automated software tests and a fictional evidence-linked example.
- Streamlit dashboard showing readiness profiles, gate results and improvement actions.

**[🌐 Open the demonstration dashboard](https://vha-airaf-malo33l8wwaawrdvx5odvm.streamlit.app)** · **[📁 Explore the framework](https://github.com/VictoriaE-ai/VHA-AIRAF)**

**Stack:** Python · Streamlit · JSON · Assessment methodology · Responsible AI governance

*The framework is not independently validated and does not certify or authorise an organisation to deploy AI.*
